Тестовое задание для DevOps-инженера (Яндекс Браузер для организаций).

В репозитории лежат три части задания:

A1 — статическая страница на nginx внутри Docker. Собрал образ на базе nginx:alpine, внутрь положил index.html. Контейнер поднимается через docker run с пробросом порта 8080→80. Также добавил docker-compose файл, через который можно поднять тот же сервис одной командой. Проверка через curl http://localhost:8080
. В ответ приходит «Hello from Alexey». На вопрос из задания «как доставить новый index.html без пересборки образа» — можно примонтировать файл из хоста через bind mount и nginx будет отдавать обновлённую страницу без билдов.

B1 — bash-скрипт clean_old_logs.sh. Принимает путь к директории и количество дней, находит .log файлы старше указанного срока, показывает список и спрашивает, удалить или нет. При подтверждении удаляет. Если аргументы не заданы или директории нет — выводит сообщение. Все сообщения и usage на английском, потому что делал работу на удалённом сервере без русской локали и не стал ставить дополнительные пакеты.

B2 — текстовый ответ про ситуацию с Git. Если работа не закоммичена, а нужно срочно переключиться на main, то можно сохранить изменения через git stash push, перейти на main, сделать фикс, вернуться в ветку и восстановить изменения через git stash pop. Ответ тоже на английском по той же причине — работа шла на сервере без русской локали.

Структура репо простая: папка test-project с Dockerfile, docker-compose.yml и index.html, отдельный bash-скрипт и текстовый ответ по Git. README решил оставить на русском, потому что так проще объяснить, что где лежит и почему в коде английские комментарии.
